Widget dev preview

This page is dev-only — it's not part of the built dist/widget.js bundle. It exists so editing anything under src/ hot-reloads instantly here, without running npm run build first.

It normally would read its config from a <script data-api="..."> tag, the same way a real embed does — but that trick (document.currentScript) doesn't work for ES modules, which is what Vite's dev server needs to serve live .ts source. So this page wires the controller directly instead, with the same effect.

Make sure apps/server is running first (npm run dev:server), then just edit any file under src/ and save.
