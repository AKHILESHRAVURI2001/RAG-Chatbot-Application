# 5. S3 Buckets

← [Back to overview](README.md) | **You are here: Step 5 of 13** | ← Previous: [4. ElastiCache (Redis)](04-elasticache.md)

Search for the **S3** service → **Create bucket**, twice. Bucket names must be **globally unique** across all AWS customers, so add some random characters to the end of yours (e.g. your initials + today's date).

**Static bucket** (e.g. `mcb-static-yourinitials123`):
- Leave **Block all public access** checked for now — CloudFront will get access through a bucket policy instead, not by making the bucket public. **Create bucket**.

**Artifacts bucket** (e.g. `mcb-deploy-artifacts-yourinitials123`):
- Same — fully private. **Create bucket**.

The actual file uploads into these buckets — the built admin dashboard, `widget.js`, the packaged server code — happen later, in [step 10](10-build-and-upload-code.md), after CloudFront exists so the bucket policy has something to reference.

## ✅ Checkpoint before moving on
- Both buckets exist, both fully private (public access blocked)
- Write down both exact bucket names — you'll need them repeatedly in steps 6, 9, 10, and 12
